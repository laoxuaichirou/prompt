# IMG-EC-04 节日促销底图

原创模板 · ecommerce

## 使用输入

`festival`, `palette`, `product`

## 提示词

```text
为 {{product}} 制作 {{festival}} 电商活动底图。产品保持参考图一致，单主体置于画面中下部，占高50%；采用 {{palette}} 配色和简洁几何展台，顶部35%留空供后期排版。商业摄影与精致场景搭建，竖版4:5，不生成价格、折扣、标语或品牌。
```

## 验收

- 顶部可排版
- 无价格伪造
- 主体突出

模型与分辨率、比例、透明背景能力以实际接口为准；商品精确保真需有参考图并人工比对。
