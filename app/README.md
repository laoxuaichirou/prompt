# 提示词去重合并器

将 PromptBench 提示词库导入单文件网页，用确定性文本算法找出重复候选，逐簇人工裁定，再导出干净数据与台账。没有任何自动确认或后台提交。

**交付状态：功能已实现并实测；未宣称全部验收通过。** 附件的两项数值预期未能按文字规格复现；云端浏览器管理员策略阻止 `file://` 验证。这两类限制保留在 [TEST_REPORT.md](TEST_REPORT.md) 和原始日志中。

## 使用

1. 下载并解压交付包。应用只有 `promptdedup.html`，其他文件是说明、测试与证据。
2. 在允许本地网页的现代浏览器中双击 HTML。无需安装、后端、构建、网络或账户。首次显示附件内嵌的 8 条样例。
3. 选择或拖入 `prompts.json`。期望 `schema: "promptbench/1"` 与 `entries` 数组；无效结构或重复 ID 会显示常驻红色错误，阻止导出，绝不静默过滤。
4. 查看候选簇，选择完整提示词作为主条，勾选要并入的条目及补入片段，点击“确认合并”。默认推荐不会生效。不合并需填写原因。编辑已确认裁定后，须重新确认。
5. 导出三件套。若浏览器阻止连续下载，分别点击三个单独导出按钮。请同时导出“裁定备份”保存完整操作进度。

页面无外部资源，全部脚本、样式、样例内嵌；无远程请求，无凭证输入。正文和 `source` / `image_ref` 都是只读数据，不会打开这些路径。

当前云端 Chromium 返回 `net::ERR_BLOCKED_BY_ADMINISTRATOR`，因此这里未完成双击及断网刷新验证，也没有绕过策略。其他功能实际使用仅绑定回环地址的静态服务验证。仅在需要同样的备用方式时，从解压目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

然后在浏览器地址栏打开回环地址、端口 8000 下的 `promptdedup.html`。此方式用于备用预览，不是应用运行依赖；不能用它证明 `file://` 已通过。

## 算法与参数

- 默认阈值 `0.50`，范围 `0.30–0.95`。调整滑块后先显示“需重算”，停顿 350ms 后自动重新计算；其他设置需点击应用。旧结果不能导出或裁定。
- 默认权重：LCS `0.6`，字符 2-gram 余弦 `0.4`。两项均可修改，须合计为 1；不偷偷重新归一化权重。
- 默认开启：全角转半角、中文标点映射、折叠空白并去首尾空白、英文小写、去噪声前后缀、短串护栏、排除“模板生成”。默认不分桶。
- 标点映射：`，、→,`、`。→.`、`；→;`、`：→:`、`！→!`、`？→?`、`（）→()`、`【】→[]`。不删除全部标点，不删除句内空格，不做简繁转换或语义改写。
- 字符长度、LCS、2-gram、差异均按 Unicode 码点计数。LCS 的相似度用精确的位并行算法加速，并用独立逐格动态规划交叉核对；不是近似 LCS。
- `L = 2 × LCS长度 / (lenA + lenB)`。
- `C = Σ(aᵢbᵢ) / (√Σaᵢ² × √Σbᵢ²)`，其中 a、b 是相邻两个字符的**词频**向量。
- `score = 0.6 × L + 0.4 × C`。任意一条归一化后少于 12 字，只比较归一化字符串是否完全相等；相等 1，否则 0。空串同样只做完全相等判断。
- 长度比小于 0.4 或大于 2.5 直接剪枝。短语 Jaccard 只在差异面板作为诊断列，不影响阈值。
- 达阈值的边用并查集合簇，只展示至少两人的簇，按最高相似度降序。传递链可能连接未直接达标的两条，请人工复核。
- 不使用中文空格分词、第三方库或词表分词。

### 噪声词表

默认 13 个：请基于、请生成、生成一张、一张、图片、画面、要求、注意、必须、输出前检查、检查、确保、尽量。

版本为 `boundary-noise-v1-<词表文本指纹>`，随实际词表进入报告。仅反复移除前缀或后缀及紧邻边缘的分隔符；**不全局删除句内的“画面”等词**。默认开，可关闭、逐行编辑。参数快照记录完整词表和全部归一化开关。

### 复算一对

内嵌 S1/S2 归一化后长度 43/52，LCS 长度 35，2-gram 余弦为 0.5185629788417314。

```text
0.6 × (2 × 35 / 95) + 0.4 × 0.5185629788417314 = 0.6495304546945873
```

页面浏览器控制台可运行以下代码，直接对原文重新准备向量、计算分数；不依赖当前页面是否载入其他数据：

```js
const sample = JSON.parse(document.getElementById('sample-data').textContent);
const c = PromptDedup, p = {...c.DEFAULTS};
c.similarity(c.prepare(sample.entries[0], p, 0), c.prepare(sample.entries[1], p, 1), p);
```

完整归一化字符串、LCS 长度和分项分数在 `results/calibration-details.json`。

## 人工裁定和无损导出

- 默认选原文最长的完整提示词；有“片段”标签的条目永远不能成为主条。全片段簇只能保留待裁定或填写理由不合并。
- “模板生成”默认不参与比较，但保留在数据、独立列表和最终导出中。关闭排除后才参与。
- 默认其余成员全部勾选并入，但只有点击确认后才真正执行。勾选补入片段按点击顺序追加，以中文逗号连接，保留片段原文。
- 主条 tags 去重并集；slots 按 key 合并，同 key 同 default 保留主条描述，同 key 不同 default 阻止对应条目并入，完整保留该原条目。不会覆盖 default，也不会悄悄丢掉冲突字段。来源未实际并入的补片段不会生效。
- 合并增加 `merged_from` 和逐项对应的 `merge_sim`；已有合法来源台账继续保留。根 schema、version、未知字段和未合并条目保留，不增加自定义 schema 字段。
- 不勾选、未裁定、不合并、冲突阻止的条目全部保留。输入对象和原输入文件均不被改写。

### 三种导出

1. `prompts.dedup.json`：完整 `promptbench/1` 数据；只在已实际合并的主条新增或延续 `merged_from` / `merge_sim`。
2. `merge_report.md`：每簇主条、实际并入及相似度、补片段原文与执行情况、因并入删除的条目及原因、未合并及阻止原因。带阈值、权重、噪声表版本/内容、条目总数、实际比较次数、剪枝次数、排除数、分桶范围等参数快照。
3. `conflicts.csv`：UTF-8 BOM，列为 `类型,条目A,条目B,相似度,冲突内容,建议`。包含槽位冲突、阈值 ±0.08（含端点）边界对、跨主题达阈值对，另列尚未裁定簇。逗号、引号、换行正确转义，并为电子表格公式前缀做防执行处理。

## 进度保存

本地存储保存输入、参数和裁定，按数据及参数指纹分开，避免旧裁定套到不同库或新参数。刷新会重新计算并恢复当前上下文中的裁定；修改参数后不会静默沿用旧合并。

本地存储配额和 `file://` 下的隔离策略由浏览器决定，常见约数 MB，不能承诺固定 5MB。写入失败显示常驻红色错误并提示“先导出一次再继续”；内存里的数据可继续导出。读取坏存储时不自动覆盖，需主动重试保存或重新导入。

`promptdedup.session.json` 是独立的裁定备份，包含原数据与所有保存过的参数上下文，可用“恢复裁定备份”恢复；它不是 PromptBench 库文件，不应作为 `prompts.json` 导入。页面不上传本地存储或备份。

## 性能与护栏

计算按约 160ms 预算分片，通过零延时计时器让出主线程；进度栏持续显示已处理/总数及已等待秒数。超过 1200 条强制展示按主题分桶提示和专用按钮；开始前显示预计耗时。预估只是粗估，依文本长度和设备变化。

Node 中对内嵌样例复制的 1200 / 2000 条合成数据做了实际全库压力测试，详细时间与进度间隔在测试报告中。**不是用户真实 403 条库实测**。为避免数组内存失控，单次超过 600 万候选对会明确报错，要求分桶或分批；不会静默删条目。全量分数缓存约每对 8 字节。差异面板超过 3000 万 DP 格会明确说明未计算，并保留全文；相似度仍使用全文。

分桶只比较同主题，跨主题重复会漏检，报告明确标注。算法不具备同义词理解；高分不等于语义可以合并。

## 复核与测试

应用不依赖任何测试运行时。以下工具只用于交付检查，使用已有 Node / Python 标准库，不安装依赖：

```sh
node tests/core-test.cjs
node tests/browser-test.cjs
python3 tests/verify-package.py
```

- 核心脚本：功能错误退出 1；功能通过但附件数值断言未全部通过退出 2；全部通过退出 0。`passed` 表示功能检查，`acceptancePassed` 同时包含附件数值断言。
- 浏览器脚本：需要系统已有 `/usr/bin/chromium`；不使用安装包。实际通过的操作、被策略阻止的 file 导航分别记录；受阻退出 2，功能故障退出 1，全部通过退出 0。它只为测试建立 localhost 服务，不属于单文件应用。
- 重跑脚本会更新 results 日志/截图，因此冻结包的哈希会变化。请在副本中重跑，保留原交付作比较。
- `SPEC.md` 是原始上传指令的逐字副本。审查范围见 `CODEX_REVIEW_INSTRUCTIONS.md`。
