## 1. 对所有案例立即生效的修订

### 1.1 将一个“成功”拆成六层结果

| 层 | 通过条件 | 不通过时记录 |
|---|---|---|
| T0合同/前检 | 资产齐、模式/长度/参考配额合法、所有标签可解析、生成授权已到 | BLOCKED_INPUT / BLOCKED_CAPABILITY；不算模型失败 |
| T1传输/任务 | 发送有效prompt和条件；记录ID；等待终态；超时/取消/失败区分 | FAILED_TRANSPORT / FAILED_SERVICE / TIMEOUT；completed非质量通过 |
| T2可读文件 | 文件可解码；video/audio streams与预期一致；frame_count/sample_count记录 | FAILED_CONTAINER / FAILED_AUDIO_ENCODE；保留已生成的视频/波形 |
| T3原生片段质量 | 身份/动作/文字/声音按本案合同逐项检查 | FAIL_NATIVE_<dimension>，不能被后期掩盖 |
| T4装配质量 | 总时长、切点、上下文、音轨、claims、Logo/UI正确 | FAIL_ASSEMBLY；不倒推模型失败 |
| T5交付 | 素材版本/来源/参数/原件/后处理可追溯 | FAILED_EVIDENCE；文件存在但不可复核 |

推荐终态：NOT_RUN、BLOCKED、PASS_NATIVE、PASS_POSTPROCESSED、FAIL、PARTIAL、INCONCLUSIVE。复合任务每个维度保留单独结果；不得“只要最后有MP4就全通过”。

### 1.2 统一证据字段（新增，不要求改模型）

每次尝试保存：

```text
skill_path / skill_commit / skill_sha256 / language_variant
H3_source_commit / HF_model_revision / every_weight_sha256
backend_name / backend_commit / custom_node_commits / startup_flags

quantization / LoRA hashes+strength / sampler / scheduler / steps / sigma_shift
mode / requested_seconds / requested_ratio / requested_resolution
prompt_original / prompt_compiled / submitted_payload / char_count / utf8_bytes / prompt_sha256
reference_file_order / role / sha256 / dimensions / duration / audio_track_enabled
service_effective_prompt_or_hash_if_available / job_id / lifecycle_timestamps

native_quality_results / postprocess_operations / final_output_sha256

```

后端不返回effective prompt就填`not_exposed`，不能填“已验证全文到达”；可记录客户端序列化字段hash，但它只证明发出端。权重/后端未知就如实unknown，不用文件名代替hash。不同后端相同seed未必同随机序列，不能声称逐像素公平对照；配对优先在同后端/权重/参数内做。

### 1.3 调度与样本量

第一轮先T0，随后每案可先1个smoke样本定位工具链；有意义的模型对照建议预注册3个seed，按每seed各臂配对，所有失败/重试保留。3次不足以证明普遍稳定，只报告`通过数/实际尝试数`，不报告置信很高的“成功率”。选择最佳样片用于展示时另列best-of-N，不能替代原始分母。

同一轮只变一个因素；不能同时换权重、移除LoRA、改步骤数、升级ComfyUI再归因其中一个。模型失败后的回退组另编号；跨模型对照不是同一模型修复。

### 1.4 前检规则

- 单次生成按仓库4–15秒；短于4秒的**剪辑镜头**由合法片段裁出，不直接传2秒。第三方长于15秒路径作为额外实验，不能更新官方规格栏。
- FL2VA最多两张关键帧，0/1/2对应文本/首或尾/首尾；多身份/三产品锚点用匹配的Ref2VA路由。
- Ref2VA≤9图、≤3视频且各2–15秒总≤15秒、≤3音频且各2–15秒总≤15秒、文件合计≤12；60秒master留编辑层，调用层用合法窗口。
- 选H3时素材原生24fps；30fps是品牌规划时钟，转换要以秒为中介。视频实际取整由后端记录，不假定统一帧数公式。
- 明确声音路线：`native-full`、`native-sfx-only`、`master-reuse`、`external-voiceover`、`silent`；明确文字路线`native-typography`/`verified-plate`/`post-overlay`。
- Base用三字段，Ref用六字段；所有Subject/Picture/Video/Audio引用有实际绑定。视频有声音不自动创建Audio标签，必须记录是否启用。

## 3. 逐案具体修订

### V01｜最小T2VA链路：不再以服务健康/返回ID判通过

**固定输入**：6秒、16:9、Base768p、低动态单物体、无文字/人物；先SFX-only，再明确完全静音控制。采用base三字段，第一镜无cut timestamp；静音条件按规范两个音频字段适当N/A。固定现有权重/采样/后端，不安装最新包。

**执行臂**：A为当前可用请求；B只更换同语义结构化prompt（若当前已经规范，可不做冗余B）；C仅改变声音策略。轮询到本后端实际成功终态；服务失败、未知状态、取消和超时分别保存，不无条件下载。若要验证示例缺轮询，用mock任务状态，不发额外模型请求；这项审计尚未执行mock。

**观测**：保存实际payload与hash、服务完整prompt可见性、各阶段耗时、所有响应与输出；ffprobe和解码帧数、请求秒数偏差；前后300ms听检，记录额外音节、click、截音。检查时间周期闪烁，但不直接套#85的17帧成因。

**判定**：能解码且预期动作存在才PASS_NATIVE；尺寸/FPS/音轨不符分别失败，静音控制出现非请求音乐不能通过。边界允许误差需在具体后端登记，不能根据现有演示自动给所有任务宽容。若没有用户指定，报告原始偏差而不伪造“官方±几帧保证”。

### V02｜I2VA保真：先看原始素材，再看“像不像”

**输入**：一张可核对产品/物体参考（非真实品牌更利于隔离几何）；标注外轮廓、部件数、主色、背景地标、未有配饰；6或8秒合法片段，低幅运动。

**臂**：A首帧I2VA低动态；B只增加一个明确动作；若有台词串扰风险，另组同视觉有/无一条台词，不能与A/B混在同次比较。要调查运行时回归，保存旧环境并在独立快照逐因素比，不直接升级。

**观测**：批准图、真正解码首帧、每秒帧、动作最大变化点、末帧；对结构/字标/主色/新增物逐项pass/fail。有Logo时人工比对原件，不用OCR正确代替图形正确。

**判定**：参考主要几何/身份损坏即失败，画面“更漂亮”不抵消；画面生成出只在台词提到的物体记semantic leakage。任何alpha、分层工程、像素等同均不列默认通过项，因为没有此保证。

### V03｜FL2VA与L2VA：把“参考图”改为有时序语义的锚点

**输入**：同色纸面/闭合纸门首帧A，完成组装/打开纸门尾帧B；单一连贯动作，6秒；两图主体、光位、构图可达。

**臂**：A FL2VA的A→B，B L2VA只有B并推断合理开场，C普通Ref2VA只参考B（比较语义差异，不声称模式等价）。使用规范首行与末镜对齐时间；payload的关键帧role/index按实际后端映射记录，不臆造通用末帧index。

**观测**：实际首末帧与锚图、路径是否连续、是否提前出现完成图、边缘形变、纸片数量、实际帧数及stream时长。

**判定**：FL首尾均达+中间路径可读；L2只要求结尾合同，不能要求开头等同A；普通Ref不达尾帧不等于L2失败。为V07选路时以该结果为证，不默认三模式都保证末帧。

### V04｜Ref2VA：将参考保真、音色参考、原音复用拆成子案

**V04a身份**：两张明显可区分的人物或原创角色+一场景；固定发型/服色/道具/左右，低动态6–10秒。以Subject标签定义角色，场景另Subject，不新增同名克隆。

**V04b多轮声线**：A-B-A三轮短对白，英文或中文各开组；S1/S2保持稳定，两份干净短音色参考，分别2–5秒且总≤15秒，台词只出现在d块。相同seed比较：A官方稳定ID；B只取消未经编号的笑声/叹气；C仅微调时长但仍≤15秒。社区S1/S2/S3+复制音频作为可选D，显式记`NONCANONICAL_EXPERIMENT`，不与规范组混报。

**V04c中文参考音频重复/截音**：借鉴#95的控制结构，但不称已复现附件：A有参考音频+合法绑定；B断开音频保留原文，只作悬空标签诊断；C断开并清理相关音频引用，台词/场景不变。B为故意不合法的prompt诊断，不能当正常模型质量控制；替换音色另开D，不同时调采样/LoRA。

**V04d音频复用**：将`fully_copy`、`reference`分开；在复制组比较解码PCM的时间相关性/起点/时长/音频内容，不要求AAC压缩文件二进制相同；严格相同音轨可在后期直接复用，但结果标PASS_POSTPROCESSED。只参考音色组不应复制源台词。

**观测**：每轮人工辨认说话人、盲听声线、转写逐词、首音/尾音、重复词、口型起止、listen时嘴闭合；视觉身份与声线单独评分。参考与输出未经保留的视频不进入可核对分母。

**判定**：任意一轮明显串声即声线失败；转写正确不等于声线正确，嘴动对不等于声线绑定正确。#95原作者丢失输出导致证据不足，不能填写它的历史成功/失败率代替本测试结果。

### V05｜知识MV：新增“知识事实不被节奏篡改”硬门

**输入**：一段已核查知识材料、用户锁定歌词或旁白、单条master音频和实际时间窗、角色/场景/文字参考分离。先15秒，后30秒编排另案；无唱词内容不自动生成歌词。

**修订**：把2–5秒shot写成编辑窗口；每次生成≥4秒且留足裁切，避唱词中段切断；连续镜头提尾帧必须串行，独立硬切镜头可并行但需显式依赖表。master全长由编辑层管理，每段输入音频窗口合法。

**臂**：A无口型知识B-roll+master；B同一短句要求演唱/口型+文字；二者是不同能力测试，不做“无口型更容易所以模型修复”的解释。

**判定**：事实无新增错误、歌词/画面字逐项一致、无眼嘴遮挡、切点按计划；口型用逐帧人工与音素起止记录，建议≤2帧偏差只是我们的目标而非官方规格。speed-ramp改变口型时不得只报节奏通过。LUT/颗粒只解决视觉包装，不能计作身份修复。

### V06｜纸艺：用一份唯一时间表替代冲突推荐镜数

**输入**：一个知识机制、16:9、30秒项目，建议5个6秒编辑窗口；若后端输出偏长需裁入窗口。四深度面/4–7纸层、一个paper host、一个模型。5×6是审计建议，不是引用官方唯一镜数。

**修订**：先做单个5–6秒I2VA小样检验厚度/纸影/层间parallax，再批准全片；旁白需明确开启。原文快捷STEP17错位通过阶段名称规避，单图prompt-only不自动合成旁白。

**验收**：科学对象关系正确；至少四个可辨深度面；小幅stepped motion/纸机关而非塑料CG；标签无错；BGM文化匹配且旁白可懂。旁白与目标偏差>20%执行明确决策，不默认接受；小于20%也不能自动宣布精确时长合格。尾音问题单独听检。

**回退**：先修预览/运动复杂度；若精确知识图表文字无法原生生成，可声明后期替代，不能取消原生失败记录。

### V07｜纸拼贴：修正“完成图当首帧”的潜在路由错误

**输入**：3个原句，各3–6大物件，三张已批完成尾帧，统一纸质/色板；每段4秒，16:9，SFX-only。

**臂**：A按V03验证过的尾帧语义；B故意首帧I2VA同完成图仅做语义对照，预期可能不产生从空底组装，不能把B当正确合同。默认不传字幕/VO/BGM。

**观测**：开头颜色、物件逐片到达顺序、轻bounce/press/pause、最终布局相似、无camera/zoom/morph/new objects、纸SFX事件、是否误加人声音乐。

**判定**：无所需SFX记音频失败而非“无声也通过”；无请求BGM或旁白亦失败。原音里混有BGM无法干净移除时可选择重生/后期SFX路线，另记处理，不假定原生输出有独立stems。

### V08｜3D：镜头表通过不能替代最终视频通过

**输入**：30秒小故事，建议5个6秒镜头；最多2主要角色，标注角色卡与无人场景；每秒五要素，完整六列与hook分布，最少一个交接道具。

**修订**：T0检查6项官方self-check外，再加每次请求4–15秒/参考额度；文本分镜权威；铅笔图只人审；模型选择与resolution记录独立。每镜保存当前资产版本/依赖关系。

**观测**：角色左右/服装/道具、门框位置和光位、退出位置、动作完成度、镜头之间handoff。可加单镜A-B-A对白子案，走V04音频评分；不要在所有镜塞多人对白。

**判定**：标记char/scene/shot/hook、纸笔线稿、多宫格等任何非请求残留即清洁失败；身份错误片不进入装配。fallback换Seedance需独立记录及新审查，不能写H3通过。明确重试预算“初次1+最多3次重试”或另一选定制度，避免原文第三次计数歧义。

### V09｜游戏：把高密度UI与双人动作分项验收

**输入**：两短英文昵称+原创游戏名、两身份/身形对比、非黄色的明确风格色板，16:9/15秒；采用两模板并确认一图。

**修订**：静帧先核角色映射/菜单布局，后生成；必须逐阶段回填UI字及动作。无height_ref时记录为缺省文本约束，不留未绑定占位。清理默认黄色、性别或工业审美元素与用户风格冲突。

**观测**：0–2菜单、2–4玩家1爪、4–7玩家2重臂、7–8.5确认、8.5–10加载、10–15进入世界；名字/按钮/装备文本逐一OCR+人工；人数、左右、脸、体型、装备侧持续追踪。

**判定**：画面吸引力、UI文字、事件顺序、双人身份四类独立；不能错字但好看就整体通过。减少文字/事件后的片段是降级模板组，不覆盖原模板结果；仅视频，不测试实际游戏交互。

### V10｜手绘：新增时空因果标注

**输入**：新生活空间、一个手绘实体、贯穿色彩/尾线、明确触点与路线；15秒16:9；同语种创意稿。先不引入多主体/快速镜头或horror元素。

**修订**：为0–3/3–6/6–10/10–13/13–15秒各写一个可观察事件，最后空间级变形；如需要h3-prompt-writing编译，原稿和英文backend稿同时保存，台词原文不改。

**观测**：首触时间、接触/遮挡是否成立、实体每次变形是否保留母题、镜头落后追随时间、相邻空间路线、结尾空间变形。无需精确毫秒相机滞后保证，但要逐事件注明“实体先走/镜头后追”。

**判定**：首3秒无接触、突然新角色、跨地点硬切、CG毛绒或恐怖即合同失败；结尾美但无母题连续不算通过。原视频像素合成、mask/alpha导出均不属本案默认能力。

### V11｜产品广告：保真检查必须跨三个阶段

**输入**：一张可核对原图，建议非白/银主色且含一个清晰结构；10秒16:9、白科技风；一条经批准3–5词英文copy，三张独立锚点。

**修订**：原图→hero/detail/copy三图→最终视频，每级检查产品轮廓/部件/色/材质；有已知品牌/包装身份时不得把生成锚点当官方真实证据。视频仅三锚图及完整beat表，不能原图偷偷一起传；记录实际Ref2VA模式，避免FL2VA超两图。

**臂**：A按原生字/原生音乐；B仅减少字出现频次，仍含中段及结尾；C后期字或官方plate属于另批准的替代路线。原生音乐好时保留，不按Step10无条件替换；音乐不合格再独立替换组，窗口按5/10/15实际长度适配。

**观测/判定**：主色不变、结构不幻想、非3图顺序幻灯、无多宫格/商品墙；同一时刻一条单行copy，前后两色与动字可读；每句按原文核对，无多余符号；结尾稳定可读。字体名称/10px位移不是实际字体引擎保证；统计原生文字单独通过率。替换音乐后记PASS_POSTPROCESSED，不能洗掉原生音频失败。

### V12｜品牌长片：新增15→30→60三级及官方/实验标签

**输入**：真品牌或自有虚构品牌的可验证资产包，truth sheet/provenance manifest，明确每条claim/CTA/语言；声音路线；无需要精确出镜嘴型可先降低干扰。

**阶段A（15秒）**：官方流程范围内，核Logo/UI/主张及一条完整产品因果链。缺Hub工具只交pre-production，记录BLOCKED_CAPABILITY，不声称H3失败。

**阶段B（30秒）**：仍属常规目标范围但需多片调用；检验至少一对跨片接口、音乐衔接、身份资产持续，记录请求片段长度与实际输出。

**阶段C（60秒）**：标记`CUSTOM_ORCHESTRATION_EXPERIMENT`。可采用A报告8个7.5秒编辑窗口共1440帧@24fps；请求片段必须选实际后端支持的4–15秒并留handles。首轮硬切；转场另实验，不把重叠后总长减少误当60秒。

**音频两臂**：N每片原生音乐路线（评估是否断裂）；M经需求确认的统一master/可控旁白后期路线。M可能更可控，但属于外层编辑成功，不能宣称N原生音乐已连贯。master60秒不整条作为Ref音频输入。

**观测**：每个claim出处、每个身份资产的来源和hash、每个剪辑接缝前后0.5秒（7个接缝逐条）、颜色/几何/运动/音频能量/语义交接；完整视频全长listen，无dropout、重复语/截尾；先按24fps素材时钟再换交付fps。

**建议硬门（本审计提出）**：若合同选24fps且精确60秒，最终解码1440帧；Logo/UI不近似重建、主张零未证实；每个接缝完成审查，不能抽一处代表七处；原生与修后两个分数都交。交付30fps时另要求1800帧，并写明转码/重采样，不能称H3原生30fps。

**失败策略**：只重做坏镜+相邻接缝；缺真资产停前期；错误文字/产品不能用调色或粒子掩盖；60秒完成不自动宣布长片身份/口型稳定。若15秒基础都未过，不为追求60秒扩展无限增加模型调用。

## 4. V01–V12以外的诊断附录（不强行算成已执行测试）

- 初始化API：对weight_norm的original0/1与legacy g/v做构造期小单元实验，可独立于模型权重；本审计仅源码比较，未运行。
- 性能：#91的2.6×是社区LoT draft特定条件，独立记DiT-step、VAE、端到端、质量和硬件；不可套用当前全注意力版本。
- 安全：#96只模板渲染标记存活，运行时tokenizer/服务隔离未验证；不把它当模型生成越权实测。
- MPS：stock INT8算子缺失、5D padding、第三方FP8/GGUF可运行是不同问题；按精确commit和shape区分。PyTorch修复提交存在不等于当前轮子有修复；不直接要求升级。
- 来源：社区建议的speaker turn新ID、duration微调、去fp16 accumulation等仅单变量候选；原环境保留，效果未证实不纳入默认工作流。
