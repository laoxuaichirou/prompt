Expected Behavior

a dark green/black perfume bottle


gold bottle details


AMOUAGE EPIC branding

a specific gold frame around the box


specific box geometry


specific marble/dark background


a specific camera composition and object proportions



The goal is animation of the reference, not reconstruction/redesign of the product.


Actual Behavior

My current local ComfyUI installation produces a realistic-looking result, but reference fidelity is substantially worse than it was previously on the same computer.


The current result changes/reinterprets major reference structures:



velvet wrinkles/folds are largely removed


bottle shape/proportions change


gold frame changes


box geometry changes


background changes


important reference details are replaced by newly generated details


overall composition becomes an interpretation of the reference rather than a faithful animation



This is a reference-preservation regression rather than a general image-quality problem.


Important Regression Observation

The same type of MiniMax H3 Ref2VA workflow previously produced a highly reference-faithful result in my older local ComfyUI environment.


The current local environment uses the same model files and I have not intentionally changed the workflow or model files.


Model files:



minimax_h3_Singularity_ref2va_Pruned_v1.3_int8.safetensors


minimax_h3_video_vae_int8_convrot.safetensors


minimax_h3_audio_vae_fp32.safetensors


qwen3vl_32b_minimax_h3_nvfp4_awq_2.safetensors



RunningHub can also produce a highly reference-faithful result with the same general H3 model/workflow combination, but I am NOT reporting RunningHub as the problem. The important comparison is OLD LOCAL (good) vs CURRENT LOCAL (bad).


Sampling Observation

I used MiniMax H3 Preview Override / TAEH3 to inspect the latent during sampling.


The current generation starts diverging from the reference during the sampling trajectory itself: the bottle, box, fabric structure and other major visual elements begin moving toward a different interpretation.


Therefore I suspect the issue is occurring before final VAE decoding, potentially in the reference-conditioning or sampling path.
