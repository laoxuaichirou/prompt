# 《AI创作画布入门》课程整理

来源：用户提供的《AITOP100画布教学-第1期-AI创作画布入门-小辰老师.pdf》。**下文引用 PDF 阅读器中的物理页码，共33页**。课件自称27页，部分页脚混用24页/27页体系，因此不用页脚定位。原文件摘要与哈希见 [来源证据](../research/evidence/pdf-source.json)。本文件为重新组织的学习笔记，不公开分发原课件。

## 一句话说明

画布把“需求 → 剧本 → 分镜 → 人物/场景/道具 → 视频片段 → 成片”摊在同一工作区。节点保存内容，连线传递引用，生成结果留在节点，目的是减少素材下载、改名、重新上传和重复试错，而不是代替创作判断。〔PDF 4–8、26、31–32页〕

## 1. 学习目标与最小闭环

课程要求能实际完成：建画布并保存、区分文本/图片/视频节点、把参考素材连给下游、按输入与产出要求选模型。第一张画布只需要文本、图片、视频三个节点，连接后保存，关掉再打开仍能继续。先跑通流程，再完善布局与成片质量。〔4–5、9–10页〕

五个基本动作是缩放、平移、分组、整理、保存。分组以角色、场次或用途命名；同一场戏横向排一行，上游参考在左，结果在右。〔9、26页〕

## 2. 三种节点

| 节点 | 负责什么 | 输入 | 产物 | 产品设计启示 |
|---|---|---|---|---|
| 文本 | 说什么 | 简报、剧本、约束 | 镜头描述、提示词 | 结构化字段与自然语言并存 |
| 图片 | 长什么样 | 描述、已有图片 | 角色、场景、道具、多视图 | 生成/上传/编辑统一入口 |
| 视频 | 怎么动 | 文字、图片、视频及部分模型支持的音频参考 | 可检查的短片段 | 参数随实际模型能力显示 |

图片阶段先把外观定下来，再交给视频阶段。课程的文字参考、图片参考、视频参考，是可控程度的经验比较，不是所有模型一概成立的性能结论。〔12–14、17页〕

## 3. 资产先定稿，再引用

角色生产链：设定文本 → 挑选可用全身图 → 以该图制作面部及正侧背参考 → 定稿并命名入库。场景应提供空镜以锁定空间；道具单独定稿以锁定结构。〔15、25页〕

一张源图可以被多个视频节点引用。课程把“改源图，下游跟着变”用来解释引用关系；实际产品应该进一步区分：**未来任务使用哪个版本，已生成视频当时用了哪个版本**。建议保存不可变版本，改源图只标记下游待更新，不能悄悄重跑或改变历史记录。删除引用中的素材时提示受影响镜头，并支持归档。〔16页；版本机制是本项目的规划建议〕

## 4. 选模型时先问六件事

1. 输入是什么：文字、图片、视频，还是图片加音频？
2. 单次时长是否覆盖本镜头？
3. 分辨率是否满足交付？
4. 画幅是16:9、9:16还是1:1？
5. 是否支持音频输入/输出，具体上限是多少？
6. 一次生成几条，预算能否覆盖？

先定任务和输入，再看时长、声音与价格，最后设置画质和批量数。比较模型应保持素材和提示词不变，并记录人脸稳定、动作连贯、镜头是否乱切、耗时和费用。〔20–23页〕

课件提到 image-2.5、Seedance 2.0/2.5、H3 等名称；这里只作为课件内容记录，**没有由此认定某供应商当前提供这些接口或能力**。真实接入需按对应官方文档逐项验证。

## 5. 视频提示词的四段结构

| 段落 | 要写清楚 | 对应输入 |
|---|---|---|
| 参考锚定 | 哪份参考对应哪个角色/场景/道具，哪些特征固定 | 实际附加的资产ID与版本 |
| 分镜与动作 | 谁在什么位置做一个什么动作，景别与运镜 | 镜头表 |
| 声线与环境音 | 谁说话、语气、环境声；无音频时说明后期补 | 配音/音效计划 |
| 禁止项 | 不要的字幕、Logo、无关人物、乱切等 | 输出约束 |

不要写成堆砌形容词的长作文；固定项明确锁住，可变项具体描述。详见 [视频原创模板](../prompts/video/VID-FILM-01.md)。〔13、27页〕

## 6. 课堂练习的完整操作顺序

备好角色、场景、道具 → 从左到右搭节点 → 连接实际参考 → 写四段提示词 → 按能力选模型和参数 → **先生成一个镜头** → 检查脸、动作、机位 → 只改一处再试 → 可用后才批量 → 下载或加入素材库。〔25–28、31页〕

课程的一分钟示例拆为四段，每段约15秒、四个镜头；每段重复角色和场景锚定，并保持首尾相接处机位一致。它说明长内容要拆开生产，但不意味着每个接口都支持一次生成15秒四镜头。我们的长片方案会以可控的单镜头为最小执行单位。〔30页〕

## 7. 平台专属规则要单独处理

课件有“真人脸先添加到虚拟人像库，否则视频节点可能拒绝”的操作示例。这是课程演示平台的素材准入机制；**不能推广成所有AI视频平台的通用步骤，也不能承诺入库就必然消除错误**。规划里应由供应商适配器报告具体限制和错误原因。〔18、29页〕

## 8. 对你的四种用途的转译

| 用途 | 直接继承 | 需要补上的能力 |
|---|---|---|
| 电商 | 商品/场景先定稿、引用复用 | SKU版本、产品保真、版式安全区、批量尺寸、真实字体排版 |
| 影视素材 | 角色多视图、场景空镜、逐镜头生成 | 项目圣经、连续性检查、轴线/视线、声音轨 |
| 5–10分钟长视频 | 多段生产后拼接 | 章节与镜头表、任务队列、失败恢复、成本上限、剪辑时间线 |
| 口播自媒体 | 素材直接复用 | 按口播时间码分配B-roll，Remotion生成文字/图表/卡片动效 |

课程是入门操作课，没有解决长片调度、生产成本、模型接入协议、多人协作或Remotion工程。这些内容在 [产品规划](02-画布工具产品规划.md) 中作为新增设计提出。
