# 中文口播 / 字幕体检台

离线单文件工具：导入 SRT 或口播稿，按固定规则列出问题、时间码/行号、原文与建议，再复制或导出清单。**只读体检，不自动改稿，不导出修好的 SRT。**

交付四文件：`srt-checker.html`、`README.md`、`TEST_REPORT.md`、`UNVERIFIED.md`。应用只需要 HTML，另外三份是说明与实测记录。无需依赖、安装、构建、账户或终端。

**不是全部基线通过的声明。** 原始八项得到 3 PASS / 5 FAIL，干净样例 A 的两条及合计均零命中。FAIL 来自原期望集合遗漏了通用规则要求报告的重叠、缺少标点及超宽行，页面、下载 JSON 和报告都如实保留；没有修改原样例、阈值或断言。

## 打开与使用

1. 将 HTML 保存为 `srt-checker.html`，使用现代浏览器打开本地文件。页面包含全部脚本、样式及三组原文样例，不读取同目录文件。
2. 点击“样例 A/B/C”，或选择、拖入 `.srt` / `.txt`，也可直接粘贴。
3. 选择检查层并点击“开始体检”。修改原文、模式或开关后显示需重新体检，并禁止导出旧结果。
4. 按级别或固定规则 ID 筛选。错误、警告、提示分开计数，提示不算错误。为避免大量 DOM 卡顿，先显示100项，可继续追加；导出包含全部已处理结果。
5. 复制清单或分别下载三件套。若连续下载被浏览器拦截，使用三个单独下载按钮。所有下载都是新文件，不写回导入文件。

**当前环境的 `file://` 行为：未能验证。** 云端 Chromium 对本地页面返回 `net::ERR_BLOCKED_BY_ADMINISTRATOR`，没有绕过策略。这里实际通过仅绑定回环地址的静态页面执行按钮与下载验证；随后将浏览器设为离线。它证明已加载页面的离线处理与下载，不证明本地双击或断网刷新已通过。用户使用应用不需要这个测试服务。

## 输入、编码与行号

- `.srt` 自动选择字幕模式：按空行分块；原序号、时间码和正文保留。时间码严格为两位小时、两位分钟/秒、三位毫秒。分钟和秒为00–59；不把零时长当倒置，零时长按过短报告。
- `.txt` 自动选择口播模式：按空行或中文句号切段，保留源文件物理行号，仅运行 L2–L4。不是语义分句器，未实现复杂引号或英文缩写句界。
- 粘贴后可手动选择模式。源文件行号从1开始；同一物理行切出的多个口播段可能共用行号。
- 自动解码先识别 BOM，再严格尝试 UTF-8、GBK；支持 UTF-8 BOM，并额外识别 UTF-16 BOM。所有尝试失败或出现替换字符时显示中文错误，不静默采用失败解码的文字。
- 编辑框下始终显示实际解码方式；GBK 回退另有提示。编码存在本质歧义：某些字节同时可被不同编码有效解码，工具不能自动知道语义是否正确；请核对显示内容，可手动指定编码重读。
- 正文不写入 localStorage；仅保存检查层、文件编码等偏好。刷新后正文和结果不会自动恢复。浏览器禁用存储时仍可检查与下载。

## 检查层及固定 ID

| 层 | 开关含义 | 固定规则 |
|---|---|---|
| L1 结构 | 仅字幕模式，检查序号、时间、空正文及阅读时长 | L1-INDEX、L1-TIMECODE、L1-OVERLAP、L1-EMPTY、L1-TOO-LONG、L1-TOO-SHORT、L1-LINES |
| L2 排版 | 行宽、行尾标点、中文句读和空格 | L2-LONG-LINE、L2-END-PUNCT、L2-HALFWIDTH-PUNCT、L2-SPACE、L2-CJK-LATIN-SPACE |
| L3 朗读风险 | 逐项给出原文片段 → 建议写法，不替用户决定读法 | L3-YEAR、L3-DIGITS、L3-PERCENT、L3-DECIMAL、L3-RANGE、L3-THOUSANDS、L3-UNIT、L3-ACRONYM、L3-CURRENCY |
| L4 文字 | 两种明确重复词、连续语气词、13条小词表 | L4-DUPWORD、L4-FILLER、L4-TYPO |

- 固定边界：时长 **>7.0秒** 才过长、**<1.0秒** 才过短；正文 **>2行**；单行折算宽度 **>18**。等于7.0、1.0、18.0不报对应问题。
- 行尾按 Unicode 标点类别判断，闭引号、右括号本身也算标点。纯数字或中文数字不因此豁免行尾标点规则。
- 半角句读仅在同一行有汉字时报告；识别出的数字小数点和千位逗号不会当作中文句读错误。
- 行宽按可见字符簇估算：ASCII/半角片假名为0.5，其余字符簇为1，组合标记不独立加宽；制表符按2折算。支持时使用浏览器字符簇切分，否则按码点退化。不是字体像素宽度测量，罕见 Unicode 字符仍有边界限制。
- L2-CJK-LATIN-SPACE、L4-TYPO 只列为“提示”；其他风险为错误或警告。错别字仅命中内嵌13条固定短语，每项给理由，不做开放式语义猜测。
- 三位数字不报 L3-DIGITS；中文数字不报数字朗读规则。GB/MB 优先作为单位处理，不重复当普通缩写；不虚构 API/GPU 中文全称。常见完整日期的连字符不当作范围。
- 检测建议始终由人工复核。数字转中文用于朗读参考，不是正式财务大写；超出16位的整数采用逐位读法。

## 导出

下载文件使用输入文件名或样例名作为前缀，不保留源文件写入权限。

- `*-issues.json`：`issues` 内每项含 `rule_id`、`severity`、`layer`、`cue`、`index`、`timecode`、源 `line`、原文片段 `original`、整条原文 `text`、`suggestion` 与 `reason`。根部包含模式、开关、阈值、进度证据、`unprocessed` 等；口播无时间码时为 null。
- `*-issues.csv`：UTF-8 BOM；列为 rule id、级别、时间码、条目、原序号、源行号、原文、建议、理由。正确引用逗号/引号/换行，电子表格公式前缀做防执行转义。未实际使用桌面 Excel 验证，不能保证所有地区设置一致。
- `*-report.md`：分层统计、错误/警告/提示计数、前20条重点（优先错误，再警告，再提示）、未处理条目及原因、分片证据。
- 自测面板另可下载当次测试 JSON 与测试记录 Markdown；未运行项保持“未运行”。这不改变三件套或四文件交付结构。

## 页面内自测

点击“自测”运行固定全部层的原始八项：A2条、B4条、C2条。A合计零命中另做硬检查，包含提示。表内实际错误/警告集合与期望比较，提示另列，误报/漏报按集合差集分开计数，不生成混合准确率。

原始基线与规则互相冲突，例如 B2 的开始3.5秒早于 B1 的结束4.0秒，必须报 L1-OVERLAP；C1 无行尾标点，必须报 L2-END-PUNCT。工具保持原断言并显示 FAIL，不屏蔽规则。A 原文实际折算各15，不是说明文字的13；B1折算35.5，不是26；这些注释差异没有影响固定阈值。

“规则边界检查”使用单独标注的合成片段，验证固定阈值、缺失时间码不吞正文、空正文、行数、其余读法规则、提示级错字、口播切段、5001字跳过和5001条分批提示。它不替代原八项基线。

“2000条压测”循环样例B正文500次，重编1–2000序号，每条开始间隔10秒，保留四种时长。**合成压力数据，不是用户真实库。** 显示总耗时、让出次数、独立零延时计时器回调与最大工作片。160ms是检查预算，单条检查不可被中途抢占，因此会有少量超出预算的调度误差。

单条正文超过5000字会提示并跳过 L2–L4，仍检查结构，并在 `unprocessed` 写明范围；不是宣称超长正文已经检查。超过5000条明确提示“建议分批”。超大文件解码和初始字符串分配仍同步，详见未验证清单。

## 交付复核指令

请在允许本地网页的现代浏览器打开 HTML，断网后点击页面“自测”“规则边界检查”“2000条压测”，下载自测JSON与三件套。核对原样例没有改字、A零命中、原八项FAIL没有被改成PASS、误报/漏报分开、所有固定ID及跳过范围正确、没有网络请求或源文件写回。不要运行 Node/Python，不安装依赖，不提供密钥或用户本机路径。环境无法验证的项应注明未能验证。
