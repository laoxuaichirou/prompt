## 关键判断与边界

B版在电影负片、摄影布光、多机位布局、三视图留白、设计页简化和光影校正等项目上更合适。A版在暖胶片、黑白、轻柔焦、赛博/复古色彩及动作项上仍有保留价值。每项理由均在推荐表中，未默认选择新版。

**HDR、六项肤质和全景共8项两版待返修。** 肤质保留了同一人物，但小图差异仍弱；HDR没有足够明确的高光回收与宽容度证据；全景虽清除了边缘家具，墙顶接合仍有拐折，未认定360无缝。B版柔焦高光过强、举杯杯把不清也被保留并注明，最终这两项选A。完整记录见[UNFINISHED.md](UNFINISHED.md)。

普通原图以实际工具尺寸保存，通常为1672×941，部分为1672×940；两张全景均为1774×887。以asset-map实际尺寸为准，不放大宣称原生高清。卡片仅等比缩小并在外围留至少8%边距，缩略图从该布局缩小；没有代码调色、磨皮、加颗粒或拼图冒充独立生图。留边不补回原图已裁切内容，也不修复内部几何。

图像均为GPT效果/意图参考，未调用或验证Qwen/Krea/H3/RH/ComfyUI，没有真实胶片、镜头或灯光测量。人物、多视图、道具和场景经过助手视觉查看，没有人脸识别评分、工程或物理认证。3秒/5秒只为叙事推演。没有修改画布、前端映射、风格库或上线部署，详情见[UNVERIFIED.md](UNVERIFIED.md)。
