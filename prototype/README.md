# 创作桌 · 交互原型

直接用本机浏览器打开 `index.html`，或从仓库根目录启动任意静态文件服务器。没有构建步骤、外部CDN或API密钥；不要只复制本目录而遗漏 `../artifacts` 中的样例图。

支持四类模板、节点添加/拖动/复制/删除、引用连接与断开、类型与无环校验、滚轮缩放、空白处平移、适应/自动整理、编辑文本、撤销重做、本机自动保存、工程JSON导入导出。浏览器禁用存储或配额不足时明确提示导出。

“检查执行计划”只检查图结构，不调用真实生成接口。卡片图片是本次实际生成的PNG；视频/动效卡片显示生产计划。真实Remotion MP4在仓库 `artifacts`。

关闭浏览器前导出工程作为备份；浏览器本地存储不替代长期存储。导入只接受本原型schema v1，最多200节点、1000连线、2MB JSON；图片路径限定为本仓库生成样例。服务端持久化、素材上传、付费生成与多人协作是后续开发范围。
