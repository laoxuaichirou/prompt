# 创作桌 · 本机素材与动效工作台

从仓库根目录运行：

```bash
python scripts/studio_server.py
```

打开 `http://127.0.0.1:8765/prototype/index.html`。前端无构建步骤、外部CDN或模型密钥。请保留完整仓库：样例图/视频位于相邻的 `artifacts/`。端口被占用时使用 `--port 8766`；不同端口属于不同浏览器存储空间。

五个工作区：画布流程、素材库、50条提示词与8个Skill、A/B评审、口播动效。上传素材、填参提示词、Skill、评审选图和视频都可以加入同一画布。画布保留四类模板、拖动/平移/缩放、类型与DAG检查、撤销重做、本机保存。

支持PNG/JPEG/WebP图片和MP4；每张图片≤8MiB，每条MP4≤20MiB，最多50份，素材合计≤32MiB。按真实文件头识别类型，按SHA256去重。素材和评审保存在浏览器IndexedDB，图结构在localStorage；无法保存时明确提示导出。移除素材会检查当前画布、撤销历史和自定义对比的引用。

“导出工程”输出schema v2 JSON，包含内嵌上传素材、当前画布、个人评审、提示词和动效文案草稿；可以导入旧版schema v1图结构。导入上限46MiB，图片/视频重新核验SHA256；失败保留原图结构。内置样片使用仓库相对路径，移机时同时保留完整仓库。导入会合并旧素材，保证撤销时仍能找到资产；评审和草稿恢复为导入版本。工作区素材跨四个流程共享，目前不是多项目管理器。

A/B页面可以查看五组真实实测，也可选择两张自己的素材并排查看；支持棋盘/深/白背景与100%原像素滚动。个人选择不覆盖原始实测结论，AB04仍为needs-human-review。

Remotion三类样片可播放、定位、下载和加入画布。安装锁定依赖、系统Chrome/Chromium和ffprobe后，本机服务支持修改文案并真正重新渲染MP4；细节见 [工作台与Hermes验收](../docs/06-创作桌工作台与Hermes验收.md)。纯静态服务器或直接打开文件时仍可使用前端与现成样片，重新渲染按钮会禁用；浏览器策略阻止file://时请使用本机服务器。

“检查执行计划”只检查图结构，不调用图片/视频生成供应商；生图、AI视频模型、TTS、长片合成、多人协作尚未接入。
