# 原创技能包

共8个，按输入→执行→输出→验收组织。Hermes是否自动发现技能取决于本机版本；最通用用法是让Hermes直接读取指定 `SKILL.md`，保持仓库目录可读。不要只复制单个SKILL.md而丢失其引用的本仓库模板。

- [电商图片策划与逐图生产](ecommerce-image-director/SKILL.md)：为商品主图、场景图、详情页和SKU套图建立可复用提示词与质检流程。
- [影视资产与连续性设定](film-asset-bible/SKILL.md)：建立成年角色、场景和道具定稿，防止多镜头漂移。
- [单镜头导演与提示词](storyboard-shot-director/SKILL.md)：把场景拆成可执行单镜头，并输出锚定、动作、声音、禁止项四段式提示词。
- [5–10分钟长视频规划](longform-production-planner/SKILL.md)：以章节、镜头表、资产版本和预算组织长片，不要求模型一次生成整片。
- [Remotion口播素材动效](remotion-insert-designer/SKILL.md)：把口播时间码转成可渲染的关键词、流程和数据对照动效。
- [视频镜头与成片质检](video-quality-reviewer/SKILL.md)：区分技术检查、画面观察和未执行项目，输出可追溯质检报告。
- [提示词与上游资源归档](prompt-library-curator/SKILL.md)：按用途整理原创模板和上游索引，保留star证据、版本与许可边界。
- [Hermes交付验收](hermes-delivery-auditor/SKILL.md)：在本地复查本仓库研究、素材、原型和Remotion交付，不替代真实模型接入验收。

上游技能的固定版本入口见 [上游资源分类](../research/04-upstream-resources.md)。本目录的技能是针对本次需求编写的原创工作流，并非冒充上游技能的镜像。
