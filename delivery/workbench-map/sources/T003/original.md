核心优化思路：**“镜头景别→信息优先级适配”**—— 让表情 / 动作描述和镜头类型强绑定，近景 / 特写聚焦面部 + 微动作，中景 / 远景保留全身动作 + 简化面部细节，避免 “镜头与描述错位”（如特写出现全身动作描述）。
### 一、优化核心方案（3 个关键原则）
### 1. 景别分层：按镜头类型定描述重点
<table header-row="true">
<tr>
<td>**镜头类型**</td>
<td>**描述优先级**</td>
<td>**避免内容**</td>
<td>**核心逻辑**</td>
</tr>
<tr>
<td>特写（面部 / 局部）</td>
<td>面部微细节（眉 / 眼 / 嘴 / 皮肤状态）＞ 头部微动作（微抬 / 微侧）＞ 手部极微动作（轻触脸颊）</td>
<td>全身动作、大幅肢体摆动</td>
<td>特写只展示局部，多余动作描述会导致 AI 生成错位画面</td>
</tr>
<tr>
<td>近景（胸以上）</td>
<td>面部细节 + 头部动作 + 上半身轻动作（单手扶发 / 按胸口）</td>
<td>下半身动作、大幅转身</td>
<td>近景覆盖胸以上，聚焦上半身与面部的协调</td>
</tr>
<tr>
<td>中景（腰以上）</td>
<td>面部情绪 + 上半身动作 + 轻微下半身姿态（站姿 / 半蹲）</td>
<td>远距离移动、夸张肢体动作</td>
<td>中景兼顾上下半身，动作需自然不越界</td>
</tr>
<tr>
<td>远景（全身 / 环境）</td>
<td>全身动作 + 整体姿态 + 简化面部情绪（用 “略带笑意” 而非 “嘴角露 2 颗牙”）</td>
<td>过于细节的面部描述</td>
<td>远景看不清面部，重点是动作与环境的适配</td>
</tr>
</table>
### 2. 情绪 - 动作 - 景别绑定：按镜头选对应描述
- 特写场景：情绪描述聚焦 “微细节”（如 “眼角浅淡笑纹”“下眼睑泛红”），动作只加头部 / 手部极微动作（如 “头部微侧”“指尖轻触嘴唇”）；
- 远景场景：情绪描述用 “笼统但精准” 的词（如 “略带开心”“略显委屈”），动作侧重全身姿态（如 “双手自然张开站立”“双肩微垂踱步”）。
### 3. 输出格式标准化：自动匹配镜头类型
在提示词中加入 “镜头类型变量”，让 LLM 根据输入的镜头类型，自动筛选对应描述，无需人工调整。
### 二、落地思路（适配你的 ComfyUI 工作流）
1. 先在提示词中预留「镜头类型输入位」：用户需先指定镜头（如 “特写”“中景”）；
2. LLM 按镜头类型调用对应描述库：特写→面部微细节 + 微动作，远景→全身动作 + 简化情绪；
3. 保持原有 “动作差异度≤30%”“无夸张表情” 规则，只新增 “景别适配” 约束。
比如用户输入 “镜头：特写 + 动作：开心”，LLM 自动输出：“眼角浅淡笑纹，嘴角轻微上扬不露齿，眼神柔和，头部微侧”（无全身动作）。
