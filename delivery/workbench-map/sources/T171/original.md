优化版：
这段提示词的**核心逻辑很清晰**—— 针对**分镜连贯生成**场景，锚定 “风格 + 人物 + 光影 + 镜头” 四大一致性要素，同时要求剧情自然延续。我们可以从 **「规则明确化」「优先级分层」「输出约束强化」** 三个维度优化，让 LLM 执行更精准，也更适配 ComfyUI 工作流的自动化调用：
### 优化版提示词（适配多模态 LLM + 分镜生成）
**plaintext**
`【输入方式】：参考图 + 文本剧情描述<br>【核心目标】：基于参考图生成下一分镜图，实现剧情无缝延续+视觉高度统一<br>【强制约束（优先级最高）】<br>1.  人物一致性：发色、身形、面部特征完全不变；服饰延续参考图风格，仅做剧情推进所需的自然调整（如姿势变化、轻微配饰增减），禁止跳变<br>2.  视觉统一性：色调、光影氛围、画面质感与参考图完全一致；背景元素延续原有环境，仅做递进式扩展（如从街道转角到巷口），禁止突变<br>3.  镜头专业性：构图需具备电影感，明确包含「景别（特写/中景/远景）+ 镜头类型（俯拍/跟拍/环绕/侧移/拉远）+ 运动节奏（慢推/快切/手持感）」三类要素<br>【剧情要求】<br>人物动作、表情为上一镜头的自然衔接，符合文本描述的剧情逻辑，无违和感<br>【画质要求】<br>高清画面，电影级光影，真实材质纹理，无噪点、无畸变，可直接作为下一分镜生成的基础参考<br>【输出格式】<br>Next Scene: [连续文本，无特殊符号，无解释，单段100-200字左右]`
### 优化核心思路（可复用到其他分镜 / 连续生成场景）
1. **分层约束，优先级明确**新增「强制约束」层级，把 “人物 / 视觉 / 镜头” 这些**不能妥协的核心要求**放在最高优先级，避免 LLM 因侧重剧情而忽略一致性。
2. **规则具象化，减少模糊空间**比如原提示词的 “服饰延续衔接”，优化后明确为 “仅做剧情推进所需的自然调整，禁止跳变”；镜头要求拆解为 “景别 + 类型 + 节奏” 三个必含要素，避免输出缺漏。
3. **绑定输入输出，适配工作流**输入里强调 “文本剧情描述”，让 LLM 明确**剧情是延续的核心依据**；输出格式里强化 “无特殊符号、单段 100 字”，方便直接接入 ComfyUI 的提示词输入节点。
