工具的使用特性，也兼顾了基础的影视创作常识，具体优点体现在：<br>1. 前置「资产生成」步骤，直击 AI 生成的核心痛点<br>将角色、场景、音色资产作为 Step 0 独立前置，是整个 Workflow 最亮眼的设计，完全契合 AI 生成内容的底层逻辑：AI 无法像人类导演一样记住角色 / 场景的细节特征，而标准化的资产档案 + 一致性关键词，能为后续所有生成步骤提供「锚点」，从根源上解决 AI 生成中最常见的「角色脸崩、场景瞬移、风格突变」问题，这一设计比多数仅关注提示词拼接的 AI 创作指南更专业。<br>2. 影视工业化思维的轻量化落地，步骤闭环且可复用<br>参考传统影视制作的「剧本 - 分镜 - 拍摄 - 剪辑」流程，拆解为「小说→资产→分镜→首帧→视频→九宫格→连贯剧情」7 步，每一步输入输出明确、元提示词可直接复制修改，且加入了「九宫格拆分」「连贯剧情生成」的衔接环节，形成了单片段生成→多片段衔接的闭环，避免了 AI 视频创作中「片段孤立、剧情断裂」的问题，轻量化实现了影视工业化的「模块化创作」。<br>3. 元提示词设计高度标准化，兼顾工具特性与创作细节<br>所有步骤的元提示词都采用 \*\*「固定框架 + 可替换变量」的设计，不仅适配即梦 Seedance 2.0 的「首尾帧模式 / 全能参考模式」，还兼顾了 Midjourney/SD 等生图工具的中英文提示词、负面提示词设计，同时融入了影视创作的镜头类型、运镜方式、光影设定、情绪氛围 \*\* 等细节，让非专业用户也能生成符合影视基本审美提示词，降低了 AI 视频创作的门槛。<br>4. 重「一致性保障」，形成全流程的约束体系<br>从资产档案提取「一致性关键词」，到分镜、视频生成步骤强制保留关键词，再到附录的「一致性检查清单」，形成了从前期设定到后期生成的全流程一致性约束，同时针对角色、场景、光影、画风分别制定约束标准，考虑到了 AI 生成中易出现的细节偏差，这一设计体现了对 AIGC 技术特性的深刻理解。<br>5. 技术细节与创作结合，提供可落地的工具化方案<br>不仅有创作步骤，还提供了九宫格拆分的 Python 代码 /ffmpeg 命令、Seedance 2.0 的参数设置、AI 生图的比例 / 风格强度建议等技术细节，将「创作思路」与「工具操作」无缝结合，避免了多数创作指南「纸上谈兵」的问题，用户可直接按照步骤在对应工具中落地执行。<br>二、核心缺点：重技术落地，轻影视创作本质，实操存在断层<br>这份文档的核心定位是 \*\*「AIGC 提示词工程指南」，而非「影视创作指南」，因此从专业导演 / 编剧的视角来看，存在「技术框架完整，创作内核缺失」\*\* 的核心问题，同时在实操环节存在部分断层，具体体现在：<br>1. 影视创作维度缺失：无「剧本 / 故事核」设计，仅做小说「拆分」而非「影视化改编」<br>Step 1 为「小说剧情拆分」，但仅要求将小说拆分为 5-15 秒的片段，未做任何影视化改编的设计，忽略了「小说」与「视频」的媒介差异：<br>小说以「文字叙事、内心描写」为主，视频以「视觉叙事、动作 / 画面表达」为主，直接拆分小说会导致视频片段「文戏过多、画面单调、无镜头张力」；<br>无「故事核 / 戏剧冲突」的提炼，未考虑影视创作的「起承转合」，拆分后的剧情片段可能仅为文字的视觉化，缺乏视频的叙事吸引力；<br>无「镜头节奏」的设计，仅简单建议时长 5-15 秒，未根据剧情的「紧张 / 舒缓」设计时长，导致视频整体节奏平淡。<br>2. 分镜设计过于简化：缺乏专业影视分镜的核心要素，仅为「画面描述」<br>Step 2 的「分镜提示词生成」仅包含镜头类型、运镜方式、画面内容，缺失专业分镜的核心要素，分镜设计停留在「画面描述」层面，而非「叙事工具」：<br>无景别组合设计（如远 - 全 - 中 - 近 - 特的组合运用），仅单一标注镜头类型，无法通过景别变化营造叙事节奏；<br>无镜头语言设计（如仰拍 / 俯拍的情绪表达、主观镜头 / 客观镜头的叙事视角），仅简单建议镜头角度，忽略了镜头语言对剧情的推动作用；<br>无分镜序号 / 镜头时长 / 转场方式的标注，无法形成标准化的分镜表，不利于后续的视频拼接与后期剪辑；<br>无画面构图设计（如三分法、对称构图、框架构图），仅描述画面内容，导致 AI 生成的画面缺乏视觉美感。<br>3. 音频维度严重薄弱：仅设计「对话音色」，忽略影视音频的完整性<br>影视是「音画结合」的艺术，而文档仅在 Step 0.3 设计了「对话音色设计」，完全忽略了背景音乐、音效、环境音、声音空间感等核心音频要素，这是最明显的短板：<br>无背景音乐（BGM）的设计，未根据剧情情绪匹配 BGM 风格、节奏、时长，仅在示例中简单提及「悲凉的古风音乐」，无标准化的设计框架；<br>无音效 / 环境音的设计，如剑出鞘的金属声、云海的风声、悬崖的回声，这些细节是提升视频沉浸感的关键，文档完全未涉及；<br>无「音画同步」的设计，未考虑对话、音效、BGM 与画面动作 / 镜头运动的配合，如拔剑动作与金属声同步、镜头推进与 BGM 节奏同步；<br>无声音空间感的设计，如角色的对话是近景的清晰声还是远景的模糊声，环境音是 360° 的环绕声还是单声道的背景声。<br>4. 实操流程存在断层：部分步骤的「判断标准」与「容错方案」缺失<br>文档虽提供了步骤化的操作，但部分步骤仅给出「怎么做」，未给出 \*\*「做的好坏判断标准」与「做不好的容错方案」\*\*，导致用户在实操中易陷入「生成结果不理想，但不知道如何调整」的困境：<br>首帧图生成后，无合格首帧的判断标准（如是否符合资产档案、光影是否达标、构图是否合理），也无首帧图优化的具体方法（如提示词如何调整、工具参数如何修改）；<br>视频生成后，无动作连贯性的判断标准（如是否出现动作卡顿、角色瞬移），仅给出九宫格拆分的方法，未给出动作不连贯的修复方案；<br>连贯剧情生成时，仅给出基础的衔接提示词，无严重不一致的解决方案（如角色服装突变、场景光影反转），仅简单提及三个备选方案，缺乏实操性。<br>5. 工业化生产的扩展性不足：无「团队协作」「批量生成」「版本管理」设计<br>这份 Workflow 主要面向个人创作，从专业工业化生产的视角来看，缺乏「团队协作」「批量生成」「版本管理」的设计，无法适配多人协作的 AI 视频创作需求：<br>无资产档案的标准化格式（如 JSON/Excel），仅为纯文本描述，不利于团队成员之间的资产共享与修改；<br>无分镜、视频片段的版本管理方案，如不同版本的首帧图、视频片段如何命名、存储、对比，导致多次生成后易混乱；<br>无批量生成的优化方案，如多个剧情片段的提示词如何批量调整、多个视频片段如何批量检查一致性，仅支持单片段逐一生成，效率低下。<br>6. 角色 / 场景设计的影视化深度不足：仅做「外观描述」，忽略「表演性」与「叙事性」<br>Step 0 的角色 / 场景资产档案，仅做了外观、技能、光影的描述，忽略了角色的「表演性」与场景的「叙事性」，而这是影视创作中角色与场景的核心价值：<br>角色资产无表演细节设计，如角色的习惯性动作、微表情、肢体语言（如林云的「轻抚剑柄」是习惯性动作，但未设计其他情绪下的肢体表达），导致 AI 生成的角色动作僵硬，缺乏人物个性；<br>场景资产无叙事性设计，如场景的标志性元素如何为剧情服务（如青云崖的「剑痕石」仅为外观描述，未设计其在剧情中的作用，如触发回忆、作为决战的标记），导致场景仅为「背景板」，而非「叙事的一部分」。<br>三、优化改进方向：补全创作内核，完善实操细节，实现「技术 + 创作」双闭环<br>针对上述缺点，优化的核心思路是 \*\*「保留原有的 AIGC 技术框架，补全影视创作的核心维度，完善实操的判断标准与容错方案」\*\*，让 Workflow 从「提示词工程指南」升级为「AI 影视创作全流程指南」，具体优化方向如下：<br>1. 优化 Step 1：将「小说剧情拆分」升级为「小说影视化改编」<br>在原有拆分逻辑的基础上，增加影视化改编的核心步骤，让剧情片段符合视频的叙事规律，具体优化：<br>前置故事核提炼：先从小说中提取「核心冲突、人物弧光、起承转合」，再根据故事核拆分剧情，而非直接按文字顺序拆分；<br>增加影视化转化规则：将小说中的「内心描写」转化为「角色的微表情 / 肢体动作 / 镜头特写」，将「文字描述的场景」转化为「视觉化的场景镜头」；<br>设计剧情片段的节奏标准：根据剧情类型（铺垫 / 冲突 / 高潮 / 收尾）设计时长，如铺垫片段 8-10 秒，高潮片段 5-6 秒，通过时长变化营造叙事节奏；<br>增加镜头冲突设计：在剧情拆分时，标注片段的「戏剧冲突点」，并匹配对应的镜头设计（如冲突点用近景 / 特写，铺垫用远景 / 全景）。<br>2. 优化 Step 2：将「分镜提示词生成」升级为「专业 AI 分镜表生成」<br>参考传统影视的分镜表格式，完善分镜的核心要素，让分镜不仅是「提示词」，更是「视频生成的标准化指导文件」，具体优化：<br>设计标准化 AI 分镜表模板，包含：分镜序号、镜头时长、景别、运镜方式、镜头角度、构图方式、画面内容、角色动作、情绪氛围、光影设定、音效 / BGM、转场方式、一致性关键词；<br>增加镜头语言设计模块：在分镜提示词中，明确标注镜头角度 / 构图的「叙事目的」（如仰拍增强角色气势、三分法突出主体、框架构图营造压抑感），并匹配对应的提示词；<br>增加景别组合建议：针对每个剧情片段，给出景别组合方案（如「远 - 中 - 近 - 特」的推进式组合、「特 - 中 - 远」的拉远式组合），避免单一景别的单调；<br>增加转场方式设计：在分镜表中，标注相邻分镜的转场方式（如切镜、淡入淡出、叠化、推镜转场），并给出对应的 AI 生成提示词 / 后期剪辑建议。<br>3. 优化音频体系：新增「全流程音频设计」模块，实现音画同步<br>在原有「对话音色设计」的基础上，新增背景音乐、音效、环境音的设计框架，形成「对话 + 音效 + BGM + 环境音」的完整音频体系，并实现音画同步，具体优化：<br>在 Step 0 新增音频资产档案：设计场景的「环境音库」（如青云崖的风声、松枝声、云海声）、角色的「专属音效库」（如林云拔剑的金属声、施法的青色能量声）；<br>在 Step 1 剧情拆分时，增加音频氛围设计：为每个剧情片段标注 BGM 风格（如古风、史诗、悲凉）、节奏（慢 / 快 / 由慢到快）、时长，以及核心音效的出现时间；<br>在 Step 2 分镜表中，增加音画同步标注：明确标注音效 / BGM 与画面动作 / 镜头运动的同步点（如「0-2 秒：镜头推进，BGM 渐起；3 秒：拔剑动作，金属声同步」）；<br>在 Step 4 视频生成时，增加音频提示词模块：为 Seedance 2.0 等工具设计「音画结合」的提示词，同时给出后期音频合成的步骤（如如何将 AI 生成的配音、音效、BGM 拼接）。<br>4. 完善实操流程：为每个步骤增加「判断标准」与「容错 / 优化方案」<br>针对实操中的断层问题，为每个步骤增加 \*\*「生成结果合格判断标准」和「结果不理想的容错 / 优化方案」\*\*，形成「生成 - 判断 - 优化」的闭环，具体优化：<br>首帧图生成步骤：制定「合格首帧判断清单」（如角色特征与资产档案一致、光影符合设定、构图合理、无模糊 / 变形），并给出「首帧优化方法」（如提示词权重调整、负面提示词补充、工具参数修改、局部重绘）；<br>视频生成步骤：制定「合格视频判断清单」（如动作连贯、角色 / 场景一致、运镜符合设计、光影无突变），并给出「视频优化方案」（如调整提示词的动作描述、更换首帧图、修改 Seedance 参数、截取中间帧重新生成）；<br>连贯剧情生成步骤：针对不同程度的不一致问题（轻微偏差 / 中度突变 / 严重错误），制定分级解决方案（如轻微偏差补充一致性关键词、中度突变用九宫格尾帧作为新首帧、严重错误重新生成资产并调整提示词）。<br>5. 提升工业化扩展性：增加「标准化格式」「版本管理」「批量生成」设计<br>为适配个人创作向团队协作的升级，增加资产档案标准化、版本管理、批量生成的设计，提升创作效率，具体优化：<br>制定资产档案的标准化格式：将角色 / 场景 /
