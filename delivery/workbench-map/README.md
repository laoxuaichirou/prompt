## 建议整理顺序

**先整理商品视觉，其次服装与试衣、品牌海报、故事分镜。** 图像编辑和提示词助手适合成为这些入口的共用能力。UI、视频、音乐、TTS及文字工具先保留目录，按真实工具和需求补测。

商品入口可先挑T097换背景、T085手持展示、T018工业图鉴、T054珠宝展示、T089详情页组图做首批。这是整理优先级，不是通过排名。T085需要手掌辅助图；T018和T054仍有原测问题。

## 统一分类结构

|维度|示例|用途|
|---|---|---|
|任务入口|人像创意、商品视觉、服装试衣、海报封面、故事分镜|用户先选想完成的事情|
|主体与素材|人物、商品、服装、动物、场景、文字；单图/双图/多图|决定参考图槽和保留对象|
|风格标签|写实、3D动画、皮克斯式、水彩、铅笔、复古、赛博朋克|跨入口筛选；同一来源可多标签|
|构图与输出|单图、三联、九宫格、独立多图、多角度、脚本、JSON、视频、音频|决定实际执行和验收方式|
|处理方式|直接生成、图片编辑、先规划再生成、纯文本编译|决定是否先调用文本模型|
|可用状态|原测有图且符合、原测有问题、阻塞、缺失、未做对应媒体测试、新版待回归|保留证据边界|

例如T178的主入口是创意人像，同时可标为“海报、足球、双重曝光、可选球衣参考”；不复制成多张互不关联的提示词。服装试衣与人物写真共享身份控制，但验收重点分别是服装保真和人物创意。

“3D/皮克斯/水彩”是风格，“九宫格/多视角”是输出布局，“换背景/换装”是任务：分维度记录，组合时仍需检查兼容性。

本映射涉及75个未淘汰原条目，跨分类出现82次，部分已包含在人像预设或辅助引擎中。**这些数字不是新增预设数量，也不能与84张人像卡直接相加。**
