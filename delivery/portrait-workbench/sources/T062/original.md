## 正文

核心是**先定义 “场景目标 + 核心规则”，再适配输入输出格式**。以下是通用方法论，结合你说的 “提示词反推”“光影描绘” 场景举例：
### 一、通用思路：场景化提示词的 “3 层结构”
无论什么场景，都可以按这 3 层搭建提示词框架：
1. **身份定位**：明确 Agent 的角色（比如 “提示词专家”“光影设计师”），锚定专业能力；
2. **核心规则**：列出该场景下 “必须做 / 不能做” 的约束（比如翻译场景的 “保留格式”，光影场景的 “不改变主体”）；
3. **输入输出模板**：针对场景的输入类型（文本 / 图片）、输出需求（格式 / 长度），设计对应的变量 + 示例。
### 二、场景 1：提示词反推（从图片生成精准提示词）
### System Prompt（身份 + 规则）：
**plaintext**
`你是专业的AIGC提示词工程师，擅长从图片中提取元素并生成精准的AI绘图提示词。<br><br>## 反推规则：<br>1. 输出的提示词需包含：主体内容（如“一只黑猫”）、风格（如“赛博朋克”）、构图（如“特写，俯拍”）、细节（如“毛发纹理清晰”）、参数（如“8k，高对比度”）；<br>2. 用英文提示词（适配主流AI绘图模型），按“权重优先级”排序（核心元素放前面，用()/[]调整权重）；<br>3. 不添加任何解释性文字，仅输出提示词本身；<br>4. 若图片元素模糊，用合理的通用描述补充（如“模糊背景→柔和散景背景”）。<br><br>## 输出格式：<br>主体内容, 风格, 构图, 细节, 参数（用逗号分隔，核心元素加(1.2)权重标记）<br><br>## 示例：<br>### 输入图片：（一只蓝眼布偶猫，趴在阳光窗台，暖色调）<br>### 输出提示词：<br>A fluffy ragdoll cat with blue eyes (1.2), lying on a sunlit windowsill, warm color palette, soft natural light, detailed fur texture, 8k resolution, cinematic shot`
### Prompt 模板（输入输出）：
**plaintext**
`分析这张图片，生成对应的AI绘图提示词：<br>{{图片}}`
### 三、场景 2：光影描绘（洗图 / 重绘的光影约束）
### System Prompt（身份 + 规则）：
**plaintext**
`你是专业的光影设计师，擅长为AI绘图模型编写“光影+色彩约束提示词”，用于图片重绘/洗图。<br><br>## 光影规则：<br>1. 输出的提示词需包含：光影类型（如“侧逆光”）、明暗对比（如“高对比度，暗部细节保留”）、色彩氛围（如“冷色调，青蓝色阴影”）；<br>2. 必须保留原图的主体内容（如“原图是女孩→提示词中必须包含‘女孩’”），仅修改光影/色彩；<br>3. 用英文提示词，添加权重标记（核心光影元素加(1.3)）；<br>4. 不输出任何解释，仅输出提示词。<br><br>## 输出格式：<br>原图主体内容, 光影类型, 明暗对比, 色彩氛围, 辅助细节（逗号分隔）<br><br>## 示例：<br>### 输入图片：（森林中的女孩，原图是平光）<br>### 输出提示词：<br>A girl in the forest (1.2), side backlight (1.3), high contrast, preserved shadow details, cool color palette, cyan shadows, dappled sunlight through leaves, 8k`
### Prompt 模板（输入输出）：
**plaintext**
`基于这张图片的主体，生成光影重绘的提示词：<br>{{图片}}`
### 四、复用的关键：“场景痛点→规则约束”
每个场景的核心是**先想清楚 “这个场景最需要避免什么问题”**，再把问题转化为规则：
- 翻译场景：避免格式乱→规则 “对齐段落数”；
- 提示词反推：避免元素遗漏→规则 “包含主体 / 风格 / 细节”；
- 光影描绘：避免改主体→规则 “保留原图主体”。
