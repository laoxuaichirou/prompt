## T002 参考图分镜规划

```text
输入照片/参考素材和用户请求。基于照片与{{story}}输出原生网格或独立镜头的结构化计划，再转成生图提示词；不要把文字计划当出图结果。
身份只来自明确绑定的人物照片，不用示例姓名或测试合成人物代替。先输出可执行编辑或生图提示词，实际生成结果必须另行验收。
```

变量：
```json
{
  "story": {
    "default": "人物发现一束花，走近、拿起、观察并微笑",
    "required": true
  }
}
```
