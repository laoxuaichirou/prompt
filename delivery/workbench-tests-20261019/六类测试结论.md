# 六类工作台：本轮真实测试结论

本轮57个去重来源条目，各自选择一个最小完整用例；100张新图均已打开检查。30项符合主要可见要求，27项存在问题。所有结论为模型视觉初评，稳定性未验证。后端生图模型未知；实际工具image_gen.imagegen，属于ChatGPT适配。

同一来源可跨工作台复用，以下类别计数有交叉，不能相加当作去重总量。

|工作台|测试来源数|符合要求|存在问题|本次判断|
|---|---:|---:|---:|---|
|商品视觉工作台|11|4|7|背景替换、手持和详情组图可作为首批预设候选。单张商品照推断背面、鞋底及八角度时出现结构漂移；4K/8K不能靠提示词保证。|
|服装与虚拟试衣工作台|9|6|3|换装、去人留衣与悬浮服装已有可用样例。多动作、25格广告及多视图中的口袋、景别和姿态仍会漂移。|
|品牌海报与封面工作台|7|5|2|旅行水彩、标题白名单与双版本文字封面表现较好；留白安全边距、细节物件状态需逐图验收。|
|故事分镜与影视资产工作台|18|6|12|适合整理成“规划→角色/场景资产→静态分镜”分阶段入口。动作回退、标签冗余、物件出现时机和布局问题较多，不应标为视频能力已验证。|
|图像编辑与修复工作台|11|9|2|添加/删除/替换、身份锁定和两种调色可形成首批预设。姿态迁移会改空间细节，修复不能保证真实细节恢复或4K输出。|
|参考图反推与提示词助手|7|4|3|适合共用的反推/改写助手。必须实际编译后生图；目标模型名与权重字段只是格式，原模型未实测，反推也无法证明真实原提示词。|

## 范围边界

“符合要求”只对应test.json选定用例与inspection.json列明的可见要求。长流程里的其他子模板、缺失子页、音频、视频及外部Agent执行都未因此得到验证。原219条库的评分和上一轮证据未覆盖。本轮不是把所有来源都整理成稳定的工作台预设。
