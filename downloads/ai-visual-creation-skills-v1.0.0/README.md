# AI 影像创作 Skill 工具包

版本：1.0.0 · 整理日期：2026-10-31（北京时间）

把两份画布课程、导演 Skill、三类提示词案例、模型知识笔记及 CTX-6 方法论，整理为五个可独立使用的 Skill。默认先用图片完成角色定稿、宫格分镜和返修；视频能力可用时再输出对应镜头提示词。

## 包含什么

| Skill 文件夹 | 用途 | 推荐顺序 |
|---|---|---|
| `creative-workflow-planner` | 把点子变成故事、资产清单、镜头表和生产计划 | 1 |
| `image-storyboard-director` | 角色定稿、四/九宫格图片分镜和模型适配 | 2，主要入口 |
| `visual-consistency-reviewer` | 检查一致性、定位失败并进行单点返修 | 3 |
| `video-prompt-director` | 将已确认分镜转为视频导演提示词 | 有视频模型时 |
| `context-driven-dev` | 开发素材库、画布、批量工具时组织需求、实现和验收 | 按需 |

`examples/ash-swordswoman/` 保存本次实际生成的角色参考、初版四格、修订四格及观察记录。`references/` 保存资料来源和技术勘误。原始 PDF、RAR 和原版 Skill 未再次整包复制；本包以提炼改编的操作流程为主。

## 安装与使用

1. 解压，打开 `skills/`。
2. 将需要的单个 Skill 文件夹整体复制到工具支持的技能目录，保留内部 `SKILL.md` 与 `references/`。支持项目级技能目录的工具可按其说明使用 `.agents/skills/`；其他工具以各自文档为准。
3. 如支持按名称调用，可直接说“使用 image-storyboard-director，把这个故事做成四宫格”。不支持 Skill 加载时，将该文件夹中的 `SKILL.md` 作为规则附件提供给助手。
4. 仅加载规则不会赋予图片、视频、文件或联网工具。生成步骤使用宿主实际提供的能力；没有相应工具时交付提示词与计划，并明确生成尚未执行。

每个 Skill 的必需参考均在自己的文件夹内，可以单独复制。根目录案例与课程来源属于可选阅读。

## 直接复制的调用示例

**完整小样**
> 使用 creative-workflow-planner，规划一条 8 秒巧克力广告。只有图片生成能力，先交付两张关键帧和剪辑建议。风格暗调、材质真实、少动作，先做一条再扩量。

**角色与分镜**
> 使用 image-storyboard-director。先做一张成年女剑客的角色定稿图，确认后以它为参考生成四宫格：起势、横斩、落地、前冲。固定脸、衣服、剑和场景地标。完成后给出逐格检查结果。

**定点返修**
> 使用 visual-consistency-reviewer。右上格把横斩画成直刺了。只修改这一格的动作，保留另外三格与整张图的布局。对照原图检查是否有附带变化。

**九宫格**
> 使用 image-storyboard-director，把这四格扩成九格。先给出九个不同的信息点，确认叙事有必要后再生成；沿用已定稿角色和场景，不增加新人物。

**工具开发**
> 使用 context-driven-dev，给现有素材库加一个镜头标签筛选功能。先检查仓库，沿用现有结构，只问会阻塞实现的问题，完成实现和相关验证。

## 本轮验证与边界

- 实际完成：1 张三视角角色参考、1 张四格初稿、1 张四格局部修订图。
- 视觉观察：角色、色调和主要环境地标基本一致；初稿攻击动作偏成直刺；修订图中横向斩击更明确，其余三格视觉上基本保留。
- 观察不等于像素级一致性，未做独立多次重复、自动身份识别或统计 A/B 实验。
- 新整理的五个 Skill 尚未全部独立跑过端到端生成；既有三张图验证的是它们采用的部分方法。
- 静态分镜不能证明视频动作连贯、无闪烁、精准时长或音画同步；四格也不能覆盖原稿完整八拍连招。

生成模型和界面能力会变化。模型时长、参考数量、图片引用语法、声音支持、帧率和价格应查询当前工具，不从课程或 Skill 名称推定。
