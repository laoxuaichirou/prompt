# 统一测试题

每次只挑一个P组，把同一题逐字提供给A与B。方括号说明是测试前要完成的准备，不要直接传入不存在的文件名。

## P1：巧克力广告制作计划

> 规划一条6秒、16:9的暗调巧克力广告，先只使用图片能力预演，交付两张关键帧的镜头计划和生成提示词。两镜分别为45度略俯拍堆叠巧克力与断面微距。统一炭灰石台、可可棕和琥珀色、左上侧逆光。不增加品牌或字幕。先提交资产表、镜头表和两条提示词，暂不生成图。

控制：先比较文本；如继续图片测试，固定同一执行器与参数，分别照两组提示词调用，不由执行器再优化。

## P2：四格人物与动作

准备：提供同一张具有清晰衣服和道具的成年角色参考。最好使用独立参考；若用 evidence 中历史角色图，则记录其来自此前改编实验。

> 以本次上传的角色图锁定人物脸、发型、服装、腰带与剑，生成一张2×2四宫格，按左上到右下依次为起势、横斩、落地、前冲。人物总体由画面左向右行动。相同灰雾废墟，左断墙、右石柱，统一左上方柔光。每格一个人物、一把剑，无文字，不增加敌人。右肩与左腰等特征以本次参考图实际可见内容为准；模糊项不要编造。先输出实际要用于生成的提示词，再调用图片工具生成一张；暂不返修。

控制：都使用实际附件绑定，同格数同画幅同模型同调用预算；A课程无四格默认规则，四格来自本条共同用户要求。仅有文本时先保存提示词，图片状态not-run。

返修子题：两组都收到相同格式的检查反馈，明确“格位置、可见偏差、目标”，最多一次编辑；另记这是完整流程而非初次输出。

## P3：视频导演文本与未来视频

准备：同一角色/首图，确认视频平台能力；本题使用用户指定10秒，不从Skill推定平台支持。

> 为上传首图编写10秒、16:9的视频导演提示词。画面从首图开始：同一成年角色在雨夜站立，低头看手中未举起的道具，再抬眼望向画面右侧。缓慢推近，无切镜，无对白，只要雨声、衣物声与远处城市底噪，无配乐、字幕和新增人物。保持首图的脸、服装、道具与光线。

先比较提示词。没有视频工具，两组video均not-run，不拿图片替代。若支持视频，明确宿主的真实提交语法、模型与参数，两组相同预算提交。

## P4：开发标签筛选

> 在同一份素材管理项目基线上新增按标签筛选功能，保留已有列表行为。先检查仓库与既有测试，明确输入输出，再实现并验证正常、空结果和未知标签情况，不改无关模块。记录交互次数、实际改动和验证输出。

两组必须使用同一代码基线的独立副本，不共享前组修改。不要求自动建worktree。需同样遵守运行宿主与仓库权限；原版确认节奏与B版节奏作为交互成本记录，不能强制抹平后再比较流程。

## 原视频稿的静态迁移（非严格P组）

对灰烬剑姬或红莲利刃：先共同约定选哪些事件、多少格、是否保留原人物与动作、同一参考是否完整。两组都应用同样的转换协议并保存差异。只研究提示词迁移可用性，不据此宣称原版视频好坏。
